What it does

Everything you reach for when the bars are gone.

No accounts, no cloud, no tracking. Each app works from the phone itself, so it keeps working in a valley, on a mountain or when the network is simply down.

GPS + offline

Maps that work anywhere

Vector maps of Czechia down to footpaths, plus the whole world in overview. The built-in GPS shows where you are, with no data connection at all.

Wikipedia in your pocket

The complete Czech or English Wikipedia as text, with search. Look up a plant, a first-aid step or a bit of history without a signal.

LoRa messages

Text other SurvivalOS phones kilometres away over the built-in LoRa radio. No towers, no SIM.

Camera & voice memos

Photos and video to the SD card, with zoom. Record a direction or a thought in one tap. Without a card, photos and memos stay in the phone.

PhotosVideoVoice memosMusic

Petdoku

A quiet logic puzzle for long evenings: one seal in every row, column and region, and no two may touch. Endless levels, all solvable by logic alone.

Low Power Mode, for real

One tap on the leaf in Control Center: the screen dims to 30 %, the Wi-Fi chip is switched off completely, the display redraws at 15 frames a second and the screen locks after 30 seconds. It turns on by itself at 20 % battery.

    Help

    If something goes wrong.

    Nothing here can break the phone for good — every step can simply be repeated.

    The phone does not show up in the list

    Make sure the cable is in the side port marked P4.U and that it is a data cable; many cables only charge. Try another one if in doubt.

    Close any other program that might be using the phone (Arduino, a serial monitor). Still nothing? Open “For tinkerers” below and tick “Show every device”.

    It cannot connect, or stops half-way

    Put the phone into install mode by hand: hold BOOT, press and release RST, then let go of BOOT. The screen stays dark. Then click Install again.

    An interrupted install is harmless: the phone simply waits for the next one.

    The screen stays dark afterwards

    Do a full power cycle: unplug USB, switch the battery off, wait five seconds, switch it back on and press the power button.

    A nearly empty battery also makes it switch off right away — charge it for a while.

    The phone does not see my files

    Make sure the downloads finished — an unfinished file ends in .crdownload or .part. Copy them to the card, eject the card properly and put it back; the phone sorts them within a few seconds.

    Files larger than 4 GB (English Wikipedia) need a card formatted as exFAT. Cards of 64 GB and more come that way from the shop.

    Wi-Fi does not switch on

    Early phones left the factory with different firmware on their Wi-Fi chip. SurvivalOS replaces it by itself: Settings → WLAN, switch WLAN on and tap Update now. It takes about a minute and is needed only once.

    If it asks for the Wi-Fi chip's BOOT button, hold it, tap Continue, then let go.

    How do I run the setup assistant again?

    On the phone: Settings → More Settings → Run setup again. That is also where you switch between Full and Mini.

    Which phone is this for?

    The LILYGO T-Display-P4 V1.0 (ESP32-P4, chip revision 1.x). The page checks the chip before writing anything and refuses other boards.

    This is an early version: it runs on real hardware but is still growing.

    How do I go back to the original firmware?

    Download the file ending in -merged.bin for t-display-p4-device-v1.0-esp32p4-rev1.0 from the LILYGO releases page, then install it under “For tinkerers” below.
